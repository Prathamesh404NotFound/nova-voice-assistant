Private Mode
Private Mode blocks everything that would leave this machine — no browser opens, no network calls except to openrouter.ai. Local tools report “no local model configured” until local models are wired in.
Screen reading

macOS requires the Screen Recording permission before Nova can see your screen (needed for “what’s on my screen”). Grant it, then fully quit and reopen Nova.
