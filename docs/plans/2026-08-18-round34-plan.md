# Round 34 design — Smart recurring tasks & reminders

## Why this
Nova can create one-shot reminders and tasks, and the automation engine can run recurring tool calls — but the user cannot yet say "every Monday remind me to water the plants" or "recurring task: submit the weekly report every Friday". That is a staple capability of top-ranked personal AI assistants (2026 gap). Recurring items are a natural extension of the existing notes store, reminders scheduler, and tasks module — no new subsystems.

## What
A new L2 REVERSIBLE action `notes:add-recurring` with two flavors:

1. **Recurring reminder**: "every Monday at 9 AM remind me to water the plants", "remind me every morning at 7", "weekly reminder: gym on Tuesdays at 6 PM". Stored with {id, text, pattern: {kind: daily|weekly|monthly, days?, time?}, nextDue, active:true}. The reminders scheduler arm the NEXT occurrence when the item is created, and each time it fires, it re-arms itself for the next occurrence (fire exactly once per occurrence; snooze still works on the armed instance). Deleting/cancelling is the L2 reversible path with undo (removes the pattern + disarms the pending occurrence).

2. **Recurring task**: "add a recurring task: submit the report every Friday", "weekly task: invoice review". Same pattern store, new task row created at each trigger (done flag resets fresh each cycle; marking done only affects the current instance). "mark done" keeps applying to the current instance only.

## Where
- `src/main/notes/store.js`: recurring collection (getRecurring/addRecurring/removeRecurring/advanceRecurring), `recurringReminderCandidates(now)` for scheduler.
- `src/main/notes/reminders.js` (scheduler): when arming, check recurring; after a recurring reminder fires, call advanceRecurring and re-arm.
- `src/main/notes/plan.js`: RE_RECURRING regex routed in the notes planner (after reminder routing, before keyword).
- `src/main/notes/actions.js`: `notes:add-recurring` L2 REVERSIBLE with reverse() that restores the item and re-arms; `notes:remove-recurring` L2 REVERSIBLE.
- `src/main/notes/dispatch.js`: cases for add/remove + wording (spoken confirmation with next occurrence, removal confirmation).
- `src/main/notes/dispatch-personal.js`: `recurringConfirmText()` etc.

## Test harness
`src/main/test-recurring.js` (~55 tests): routing positives/negatives, store math (next occurrence, weekly day mapping, monthly, daily), scheduler re-arm after fire, snooze interaction, L2 reversible confirm + undo, wordless forms, empty-text refusal, zero-outbound fetch blocker, additive (no facts written).
